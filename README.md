## 👋 Hey, I’m Alok Vishwakarma  
### **Software Engineer | Backend & Distributed Systems**

I’m a backend-focused software engineer with strong experience building scalable systems using **Java** and **Spring Boot**. I work mainly on **microservices architectures** and have hands-on experience with **databases** like **MySQL**, **PostgreSQL**, and **Cassandra**, with **Redis** for caching.
